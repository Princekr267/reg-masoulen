# masoulen frontend

Vite + React + TypeScript + Tailwind CSS (v3) frontend for masoulen hackathon registration site.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   Copy `.env.example` to `.env.local` and set `VITE_GAS_API_URL` to your deployed Google Apps Script Web App URL.

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
